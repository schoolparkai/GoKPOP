GOKPOP 2.0 날짜별 강의영상 관측 그래프
작성일: 2026-10-31 (한국시간)

1. 구현한 동작

기존 '점수 보기' 화면에 '함께 쌓아 온 반응' 영역을 추가했다.
조회수 / 좋아요 / 강의 영상 점수 / 종합지수 비교 중 하나를 선택한다.
각 점의 관측일·조회수·좋아요·점수를 확인할 수 있다.
날짜별 표와 세로축 확대 선택을 제공한다.
측정 간격 3·4·2·1·1·2일을 실제 날짜 축에 반영한다.
미관측일의 수치나 주간 평균, 가상 과거 기록은 추가하지 않는다.

2. 관측 근거

첫 관측은 기존 data/public/site_data.json의 승인 기록을 그대로 사용한다.
나머지 6회는 제공된 이미지의 수치를 전사하고 사용자가 확인한 날짜를 연결했다.
이미지에 공통으로 보이는 2026.10.14는 관측 날짜로 사용하지 않았다.
관측 시각을 알 수 없는 6회에는 새 시각을 만들어 넣지 않았다.

3. 점수의 의미와 재현

기존 gokpop.scoring.calculate_i1 / gokpop_public.content.simulate를 재사용한다.
계산식·분수 정밀도·gokpop2-engine-v1 판본을 바꾸지 않았다.
I1 = 6V/(V+125000) + 4L/(L+2500)
10월 31일 I1 정확값 = 889902790/221938029
첫 관측 대비 I1 변화 = 약 +0.575688390191231점

종합지수 비교 = 최초 승인 J + 당일 I1 - 최초 승인 I1
원곡 E2 및 다른 지표는 2026년 10월 18일 승인값으로 고정한 비교다.
각 날짜의 원곡 조회수·좋아요를 새로 관측한 공식 종합지수라고 표시하지 않는다.
따라서 상단의 첫 기준 점수 69.44 및 원래 공식 기록 1점은 보존했다.
새 날짜별 공식 J 승인 사건이나 연구 원장 기록을 생성하지 않았다.
가상 직접 계산 입력은 날짜별 관측 파일에 기록하지 않는다.

7. 게시 상태

Git add·commit·push, 공개 Streamlit 갱신, 새 사이트 생성은 수행하지 않았다.
예약 수집이나 주간 게시도 활성화하지 않았다.
이 보고서는 새 기능 구현본의 로컬 검증 결과이며, 공개 배포 성공 보고서가 아니다.
